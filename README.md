# Sulynn Hago: Night Summer Heat Tour

A Nintendo-style browser game about the band Sulynn Hago touring the US in a red vintage pickup truck, finding state animals and giving them instruments so they'll join the band.

**Play it:** [tampaerdoc.github.io/sulynn-hago-tour](https://tampaerdoc.github.io/sulynn-hago-tour)

## The Band

- **Sulynn Hago** — vocals & guitar
- **Jason Wilson** — guitar
- **Will Hoffman** — bass
- **Eric Somers-Urea** — drums

## Tour Route

1. Florida (Tampa) — Alligator gets the guitar
2. Tennessee (Nashville) — Raccoon gets the banjo
3. Louisiana (New Orleans) — Pelican gets the saxophone
4. Texas (Austin) — Longhorn gets the bass
5. Colorado (Denver) — Bighorn gets the harmonica
6. California (Hollywood Bowl) — Grizzly gets the drums — FINAL SHOW

## Controls

- Arrows / WASD — move
- Z — confirm / pick up / give instrument
- X — drop / back
- M — mute music

Click the game canvas once to start the music (browser autoplay policy).

## Soundtrack

The actual song [Sulynn Hago — Night Summer Heat](https://www.youtube.com/watch?v=nUXh3QAd3z0) plays as the background music via a hidden YouTube embed.
